# Cholti Home Decor

E-commerce website for home decor products (sofa covers, bedsheets, curtains, cushion covers) serving customers in Bangladesh.

## Tech Stack

- **Framework:** Next.js 16 (App Router, React 19, TypeScript, Tailwind CSS)
- **Database:** Firebase (Firestore) — products, categories, hero slides, content, FAQs, settings
- **Authentication:** Firebase Auth
- **Image optimization:** Cloudflare Images
- **Hosting:** Cloudflare Workers
- **Domain:** cholti.store
- **Payment:** Cash on Delivery (COD)
- **Other:** zod (validation), jose (JWT), lucide-react (icons)
